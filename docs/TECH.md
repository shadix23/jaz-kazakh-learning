# Jaz! - технические детали

Подробности для тех, кто хочет заглянуть глубже. Обзор для жюри - в [README](../README.md).

## Дизайн-система

Собрана по четырём скиллам: Impeccable (P. Bakaus), animation skills (E. Kowalski), UI UX Pro Max, Taste Skill.

* **Тип поверхности - рабочий инструмент (Operate):** привычные паттерны, плотность данных, без декоративных эффектов, без надписей над заголовками, без вложенных карточек и цветных полос-акцентов.
* **Палитра «Analytics Dashboard»:** синий для данных и действий, янтарный, зелёный и красный только как статусы; светлая и тёмная темы на одних токенах (`--mx-*` в `dist/metodist.css`).
* **Типографика:** одно семейство (системный sans), фиксированная шкала 12/13/15/18/22/26, табличные цифры.
* **Движение:** единственный «авторский» момент - плавное перетекание цифр и полос при смене фильтров (520 мс, `cubic-bezier(.77,0,.175,1)`, через `clip-path`). Остальные переходы - до 300 мс, `cubic-bezier(.23,1,.32,1)`; боковая панель - `cubic-bezier(.32,.72,0,1)`. Анимируются только transform, opacity и clip-path; hover - только для мыши; при `prefers-reduced-motion` движение убирается, плавные затухания остаются.
* **Адаптив:** проверено на 1440, 1024, 768, 390 и 320 px без горизонтальной прокрутки; на тачскрине элементы управления от 44 px.

## Бэкенд

`server/` - API без фреймворков (Node ≥ 20): пространство школы, коды классов, вход ученика (подписанный токен, без паролей и ФИО), приём ответов с очередью офлайн, задания. Хранилище: файл локально, Upstash Redis / Vercel KV в продакшене. Тот же обработчик работает в `dev-server.cjs` и в Vercel-функции `api/index.js`.

| Метод | Путь | Кто |
|---|---|---|
| GET | `/api/status` | все |
| POST | `/api/workspaces` | методист: создать пространство из списка учеников |
| GET/PUT | `/api/workspaces/me`, `/api/workspaces/roster` | методист (ключ) |
| POST | `/api/join` | ученик: код класса + свой код |
| GET | `/api/student/tasks` | ученик (токен) |
| POST | `/api/answers` | ученик (токен) |
| GET | `/api/answers`, `/api/assignments` | методист |
| POST/DELETE | `/api/assignments` | методист |
| POST | `/api/correct`, `/api/summary` | ИИ (если задан ключ) |

## Данные

* Демо-школа (синтетика, подписано в интерфейсе): 6 классов (6А-6Е), 147 учеников, по 3 учителя и 3 учебника на предмет, математика и казахский язык 6 класса - по 6 тем, 5 заданий в теме, контрольная по каждой теме в свою неделю. Два сценария: перекрёстное распределение учебников и «у каждого учителя один учебник» (сравнение блокируется).
* Импорт CSV: `student_id, class, teacher, subject, textbook, topic, question_id, correct, pretest, date` + необязательные `question_text, answer, correct_answer`. Разделитель `,` или `;`, ошибки - на русском с номером строки. Только псевдонимные коды учеников.
* Результаты СОР/СОЧ хранятся в браузере методиста (localStorage). Сервер хранит только пространство школы, коды классов, ответы тренажёра и задания (Upstash Redis на Vercel, файл локально).

## Тренажёр ученика (источник живых данных)

Переключатель «Ученик» открывает тренажёр на казахском языке для 6 класса - **по тем же 12 темам, что и у методиста** (6 по математике, 6 по казахскому). Если выбрать класс и код ученика, каждый ответ сразу попадает в аналитику методиста.

* **Сабақтар:** уроки по темам программы; задания генерируются заново каждый раз (пропорции, окружность, рациональные числа, сингармонизм, окончания, частицы…), у каждого есть объяснение.
* **Барыс жолы** - оригинальная игра-раннер с 3D-барсом (three.js, процедурная модель с анимацией бега и прыжка): три полосы, вопрос сверху, нужно пробежать через ворота с правильным ответом, перепрыгивать препятствия и собирать тиыны. Сердца, комбо-множитель, рекорды по сложности, бейджи, итоговая карточка и разбор ошибок с объяснением «Неге?».
* **Чат ойыны:** ролевые диалоги. Офлайн-правила исправляют казахские буквы, набранные русскими (салем → сәлем), сингармонизм окончаний (мектепге → мектепке), частицы (барамызба → барамыз ба), тәуелдік (кітапым → кітабым), заглавные буквы и знаки. С ключом `GROQ_API_KEY` (или `ANTHROPIC_API_KEY`) на сервере включается ИИ-проверка, которая находит и объясняет любую ошибку; ключ не попадает в браузер.
* **Геймификация:** XP и уровни, серия дней, дневной план, бейджи, монеты, рекорды.

Шрифты Nunito (текст тренажёра, поддерживает все казахские буквы) и Comfortaa (логотип) - под SIL OFL (`dist/fonts/*-OFL.txt`).
