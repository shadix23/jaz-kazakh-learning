# Работа методиста: какую проблему решает Jaz!

## Кто пользователь

Методист или заместитель директора по учебной работе общеобразовательной школы Казахстана. Часто это опытный педагог старшего возраста: хорошо знает предмет и школу, но работает в Excel и Word, а не в аналитических системах.

## Что он делает каждую четверть (сейчас — вручную)

| Задача | Как сейчас | Сколько стоит |
|---|---|---|
| Собрать результаты СОР и СОЧ по классам | Таблицы от каждого учителя или выгрузки из электронного журнала, сведение вручную | часы на каждый предмет |
| Посчитать % успеваемости и % качества, уровни (низкий 0–39%, средний 40–84%, высокий 85–100%) | Формулы в Excel, ошибки при переносе | — |
| Найти цели обучения / разделы, вызвавшие затруднения, и типичные ошибки | Просмотр работ и таблиц | субъективно |
| Написать аналитическую справку по итогам СОР/СОЧ | Однотипный текст в Word по каждому классу и предмету | самая трудоёмкая часть |
| Спланировать коррекционную работу (кому и по какой теме помочь) | Списки «по памяти» | ученики теряются |
| Решить, как использовать вариативные/коррекционные часы, скорректировать КТП | Интуиция | нет обоснования |
| Оценить, какой учебник лучше | Мнения учителей | путаются учебник и учитель |

Типовая структура школьной справки по СОР/СОЧ (по образцам справок казахстанских школ): количество учащихся, максимальный балл, распределение по уровням низкий/средний/высокий, % качества, % успеваемости, достигнутые цели и цели, вызвавшие затруднения, выводы и меры ([пример 1](https://docs.google.com/document/d/1N64PlOCzuf6f8dUye5E60gFrZ_1jKy4Q/export?format=pdf), [пример 2](https://goo.kz/loader/load/3506354)).

Перевод процента баллов в оценку 0–39% → «2», 40–64% → «3», 65–84% → «4», 85–100% → «5» встречается в документах Минпросвещения ([gov.kz](https://www.gov.kz/uploads/2022/4/22/ba4c40c3b15cf4f3ee96c9cc86837e18_original.1429185.pdf)). Приказ, который прямо применяет его к СОЧ, мы не нашли, поэтому в продукте это пороги по умолчанию; их нужно сверить с инструкциями отдела образования.

## Какую проблему решает продукт

**Сокращает путь «таблица баллов → обоснованное решение и справка» с нескольких дней до нескольких минут и убирает субъективность.**

| Боль | Решение в Jaz! |
|---|---|
| Сведение таблиц | «Загрузить результаты»: вставка таблицы из Excel (Ctrl+V) или файл; русские и казахские заголовки; ФИО автоматически заменяются кодами |
| Подсчёт показателей | «Обзор»: успеваемость, качество, оценки «5/4/3/2», уровни — по каждому классу и итого |
| Трудные разделы | «Темы»: тепловая карта «тема × класс», задания с типичными ошибками |
| Справка | «Отчёт»: аналитическая справка в принятой структуре, на русском или казахском, скачивание в Word; по желанию — выводы, сформулированные ИИ по сводным цифрам |
| Коррекционная работа | «Ученики»: группы поддержки по темам и классам, «ядро» (≤ 40%), профиль ученика, CSV |
| Часы и КТП | «Часы»: вариативные/коррекционные часы по потребности тем, перенос — только если допускает КТП, черновик КТП |
| Учебники | «Учебники»: сравнение внутри учителя, блокировка некорректного вывода |
| Данные между СОР | Тренажёр ученика по тем же темам; ответы приходят с телефонов учеников через коды классов; рост считается отдельно от СОР/СОЧ |
| Коррекционная работа «на бумаге» | Задание группе поддержки в один клик → ученик видит его в тренажёре → методист видит, кто начал, и рост «начало → сейчас» рядом с баллом СОР |

## Решения для удобства старшего поколения

- Стартовый экран «Что нужно сделать?» — 6 крупных карточек задач вместо меню аналитики.
- Размер текста A / A+ / A++ на всех экранах методиста; базовый шрифт 16 px, кнопки от 44–48 px.
- Кнопка «?» рядом с каждым термином: объяснение простыми словами (успеваемость, качество, уровни, прирост, надёжность вывода, ядро группы).
- Мастер импорта из трёх шагов с предпросмотром и понятными сообщениями об ошибках.
- Язык интерфейса: русский или казахский (основные экраны и справка).
- Привычные школьные термины: СОР/СОЧ, раздел, успеваемость, качество, КТП, вариативные часы.

## Что осталось за рамками прототипа (честно)

- Бэкенд есть (пространство школы, коды классов, задания), но нет учётных записей учителей и ролей; ключ методиста хранится в его браузере.
- Нет прямой интеграции с Kundelik / BilimClass (импорт через Excel/CSV).
- Привязка к кодам целей обучения ГОСО — следующий шаг (сейчас «раздел/тема»).
- Названия тем в справке на языке исходных данных.
- Объяснения на казахском и пороги оценок нужно проверить с учителем и отделом образования.
