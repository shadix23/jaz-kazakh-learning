# Проверка Jaz! по кейсу 1 и критериям жюри (2026-11-11)

Сайт: https://jaz-kazakh-learning.vercel.app · питч: `/pitch.html` · проверка: `npm test` (76 тестов) + `npm run smoke -- <url>` (сайт на Vercel: все проверки API прошли, `store: redis`, `ai: true`).

## Четыре функции кейса

| Функция кейса | Где в продукте | Статус |
|---|---|---|
| Анализ результатов по темам программы | «Тақырыптар/Темы»: карта «тема × класс», доля не освоивших, n, типичные ошибки (≥ 10 ответов на задание) | ✅ |
| Найти трудные разделы | Статусы «Қауіп аймағы / Бақылау / Меңгерілді», группы поддержки, «ядро» ≤ 40% | ✅ |
| Сравнить эффективность учебников | «Учебники»: OLS с учётом учителя, бутстрэп-ДИ, блокировка вывода при несвязном графе учитель–учебник, «лучше/хуже» только при ДИ без 0 и ≥ 5 п.п. | ✅ |
| Обоснованные рекомендации по часам | «Сағаттар/Часы»: было → стало, резерв + ≤ 20% из освоенных тем, предел +50%, экспорт КТП (CSV) | ✅ |

## Критерии жюри

| Критерий | Что есть | Риск / что сказать |
|---|---|---|
| Соответствие задаче | Рабочее место методиста по умолчанию; ученик — источник данных и инструмент помощи | Подчеркивать: продукт для методиста, не «приложение для изучения казахского» |
| Обоснованность (data-driven) | Каждая рекомендация показывает цифру: доля, n, ДИ; справка по структуре школьных справок РК | — |
| Корректность аналитики | Учёт учителя, «мало данных», два слоя данных (СОР/СОЧ ≠ тренажёр), первая попытка в уроке | Демо-данные синтетические — подписано везде |
| Практическая ценность | Импорт из Excel (ру/каз заголовки), ФИО → коды, справка Word ru/kk, КТП CSV, задания группам по коду класса | Нет пилота с реальной школой — сказать честно, показать план пилота |
| Работа с реальными данными | Журнальный импорт любого предмета (проверено тестом на биологии), пороги оценок настраиваются | Нет адаптеров Kundelik/BilimClass (нужны образцы выгрузок) |
| UX для старшего поколения | Стартовый экран из 6 задач, «?» у терминов, A/A+/A++, ru/kk, крупные кнопки | Часть второстепенных подписей кабинета ещё на русском в режиме «Қаз» |
| Технический уровень | Без сборки, бэкенд на Vercel + Redis, коды классов, HMAC-токены, тесты API end-to-end | — |
| Новизна | Замкнутый цикл «СОР → помощь → рост → СОР»; геймификация и чиби-помощник для ученика; ИИ проверяется правилами | Не уходить в «игру» — это способ доставить помощь, не суть продукта |

## ИИ (Groq, добавил Codex)

- Подключено корректно: ключ только на сервере, строгий JSON-формат, таймаут 25 с, пауза при лимите, без платного запасного провайдера при наличии Groq.
- Найдено и исправлено: модель пропускала правила (пример: «кітаптер» вместо «кітаптар») и отвечала «всё верно». Теперь ответ ИИ всегда перепроверяется правилами (`mergeAiCorrection`, тест).
- Новое: `/api/hint` для «Барыс-көмекші» — совет по теме без ответа на текущую задачу; без ИИ работает офлайн-подсказка из программы урока.

## Что осталось (по приоритету)

1. Пилот 1–3 школы: замер времени методиста до/после; сравнение «СОР до → СОР после» у групп поддержки (P1-1 в CODEX-HANDOFF).
2. Остаток казахской локализации кабинета (вкладки «Учебники», «Часы», «Тренажёр», «Данные»).
3. Цели обучения ГОСО (МЖМБС) в импорте и отчёте.
4. Роли учитель/методист; восстановление ключа методиста.
5. Проверка казахских текстов носителем языка.
