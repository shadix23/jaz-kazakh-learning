## 3 готовых логотипа

12 поз + 3 логотипа = **15 вариантов**, не 15 поз.

| Файл | Размер | Применение |
|---|---|---|
| logo-horizontal.png | 1000×320 | Горизонтальный: голова слева, слово jaz! справа |
| logo-stacked.png | 600×640 | Вертикальный: голова сверху, слово jaz! снизу |
| logo-white.png | 1000×320 | Белое слово jaz! для синего фона |

Логотипы собраны из PNG-портрета и настоящего Comfortaa Bold (ось wght=700). Это растровые PNG с прозрачностью, не векторные исходники.
